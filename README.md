# C4 Industries public website

The current website is a welcoming, media-free family studio site, published on GitHub Pages. Jason’s Brooklyn, Bronx, Puerto Rican and Air Force background informs the visible story. Shopping and social links go to the existing C4 accounts.

## Current presentation

- No images, illustration embeds, video demos, galleries or image-based social previews on any public HTML route.
- Night Vigilante character work is owner-paused. The unfinished local candidate is not a released or accepted build.
- Six featured Payhip downloads remain $1.99. Prices and catalogs vary by platform.
- Existing artwork remains truthfully disclosed as AI-generated/AI-assisted in the relevant product text.
- Checkout and digital delivery occur in the storefronts.
- Product outbound links use UTM parameters. No analytics property or page-view reporting is installed by this redesign.

## Hosting

Main publishes through GitHub Pages / Jekyll. `_config.yml` excludes archived media, old styles and supporting source documentation from the deployed website. Do not restore `.nojekyll`: it would bypass those exclusions and republish archived media. Archives remain in the Git repository and local workspace; removal from the current website is not removal from Git history or third-party caches.

## Pages

Home, family keepsakes, Letters, print collections, Creator Lab and a custom 404 page. The old Letters URL redirects to the current product page. All visitors can navigate without JavaScript. Responsive CSS, keyboard focus, semantic headings and a skip link are included.

## Discoverability

Unique titles and descriptions, canonical URLs, image-free sharing metadata, Organization/WebSite structured data, robots.txt and a sitemap. These aid discovery; traffic and search rankings are not guaranteed.
