# Asset Provenance

This file records where the public site's visual assets come from.

## Brand assets

- assets/brand/c4-mark.svg — original C4 typographic mark for this public site
- assets/brand/favicon.svg — simplified C4 typographic favicon
- assets/brand/social-card.png — C4 social-sharing card for this public site

## Product assets

Files under assets/products are copies or optimized derivatives of images already used on C4 Industries' public Payhip product pages.

They are used so the public site can show customers the real product imagery instead of substitute artwork.

Current groups:

- letters-* — Letters to My Future Family
- island-roots-* — Island Roots, City Rhythm
- everyday-belonging-* — Everyday Belonging
- daily-rituals-* — Daily Rituals

WebP versions are performance-optimized copies for the public website. Source PNG copies are retained only where useful for metadata or social previews.

## Studio assets

Files under assets/studio are original C4 editorial studies created for the public website.

They intentionally use sketchbook, block-print, graph-paper, and notebook conventions so future-project imagery reads as process work rather than finished product photography.

Current studies:

- roots-city-study.svg
- night-flight-study.svg
- ordinary-memory-study.svg
- creature-lab-sketch-01.svg
- little-world-level-sketch.svg

These images are not customer product previews unless a future product page explicitly says otherwise.

## Third-party brands

C4 may discuss platforms such as Roblox, Fortnite, or Minecraft while researching creator markets. Third-party logos, characters, screenshots, and protected artwork are not included as C4-owned visual assets in this repository.
