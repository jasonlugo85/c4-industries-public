# C4 Industries Art Direction

## Working idea

C4 should look like a small creative studio with a real desk, real paper, real drafts, and finished products—not like a gallery of frictionless concept renders.

The visual language is:

**editorial + print studio + sketchbook + real product photography**

The site can be polished without making every surface perfect.

## Live product imagery

When a product is for sale, use the actual product.

Preferred order:

1. Actual product photography or storefront preview
2. Direct export from the product files
3. Restrained editorial layout using those real assets

Do not replace a live product with a fabricated mockup that changes what the buyer receives.

## Studio studies

Future work can be expressive, but it should still look authored.

Useful visual devices include rough pencil construction, graph or ruled paper, block-print texture, screenprint-style flat color, crop marks, handwritten annotations, taped-paper or photocopy cues, visible iteration, and deliberately imperfect alignment.

Avoid glossy fantasy rendering, hyper-clean pseudo-3D scenes, anonymous cinematic people, random neon, and artwork that looks more finished than the underlying project.

## Photography

Real photography should feel observational rather than staged.

Good subjects include a printed C4 page on a desk, hands writing in a keepsake, packaging or printed samples, a workbench or sketchbook, an actual Blender/Godot/Roblox Studio work session, or finished art in a real room.

Do not fabricate people, customer reactions, testimonials, family photographs, or product-in-use scenes.

## Typography

Use typography to carry personality before adding more illustration.

Current direction:

- Serif display type for editorial weight
- Plain sans-serif for navigation and detail
- Handwritten type only as a small annotation device
- Strong scale contrast
- Short headlines

## Color

The current palette is intentionally limited: ink/charcoal, warm paper/cream, muted green, coral, golden yellow, and deep blue for occasional contrast.

Color should feel printed and tactile rather than luminous or synthetic.

## Creator Lab

Creator Lab visuals should communicate process.

Good Creator Lab visuals include a level-plan page, character turnaround sketch, rough prop sheet, UI wireframe, Blender viewport capture, or a tested asset shown in-engine.

Always distinguish research, prototype, and live-product states.

## Review rule

Before publishing a new visual, ask:

- Is this based on something C4 actually made?
- If it is a concept, does it look like a concept rather than a finished commercial product?
- Could a buyer mistake this image for what they will receive?
- Does it have a clear C4 point of view?
- Would it still work if all trend references were removed?

If the answer is unclear, revise before publishing.
